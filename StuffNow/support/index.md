# StuffNow Support

StuffNow is a household inventory app for Mac. For a problem, question or suggestion, email [daysnowapp@outlook.com](mailto:daysnowapp@outlook.com).

Include your app version, macOS version and steps to reproduce the problem. Do not send passwords or a private inventory or backup unless you deliberately choose to share its contents.

## Add, edit and organise items

Choose **Add Item** or press **⌘N**. Enter identifying details and continue through the optional fields. Double-click an item, press Return on a selected item, or choose Edit from its context menu to edit it. Duplicate creates a separate item with a blank serial number.

Search narrows the visible items. Sort changes their order. Use locations, categories and tags to organise your inventory. Command-click or Shift-click selects multiple rows; **⌘A** selects visible results. In **Settings → Data Management**, rename or merge saved locations, categories and tags.

## Reports

In **View Options**, choose visible fields and sorting, add an optional title and subtitle, and save named report presets. Presets keep view settings and filters, not searches or selected rows. **Summary** describes the matching inventory. Choose **Print / Export PDF…** in View Options to preview the report, then Print or Export PDF from the preview.

## CSV import and export

Use **File → Import Inventory from CSV…** or **File → Export Inventory as CSV…**. Import shows a preview before saving; unfamiliar columns can be mapped and conflicts require a decision. CSV is for portable inventory data; use a StuffNow backup for full-inventory recovery.

## Backups and restoration

Use **File → Back Up Inventory…** to create a complete `.stuffnowbackup` file in a location you choose. **File → Restore Inventory from Backup…** previews the file and asks for confirmation before replacing the current inventory. This restores inventory data, not an App Store purchase.

StuffNow also retains up to seven recent automatic daily backups after inventory changes. These are local to the Mac, not a cloud backup service. Keep a manual backup in a safe location before destructive changes.

## Storage, accounts and sync

Inventory and automatic backups are stored locally on your Mac. StuffNow does not upload inventory, provide cross-device cloud sync, or require a StuffNow account. Files you export or back up can be affected by the backup or cloud-sync settings of destinations you choose.

StuffNow is an inventory app, not a receipt, photo or document vault. Notes can record where you keep those files.

## Currency and reset

Choose the currency in Settings. This changes display formatting; it does not convert stored purchase values.

**Reset StuffNow** at the bottom of Settings clears inventory, saved report presets, view settings, currency choice and internal automatic backups. **Back Up & Reset** first saves and checks a backup; **Reset Without Backup** requires confirmation. Your separately saved CSVs, PDFs and manual backups are not deleted.

## Purchases and further help

StuffNow is a one-time App Store purchase, not a subscription. It has no in-app Upgrade or purchase-Restore controls. For downloading a previously purchased app, use the App Store with the purchasing Apple Account.

The Mac’s **Help → StuffNow Help** opens the app’s built-in guide. For further help, email the address above.
